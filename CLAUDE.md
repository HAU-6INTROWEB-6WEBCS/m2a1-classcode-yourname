# WebCS M2A1

This is a public HTML starter template for WebCS class 2006, CS-101. Students create private activity copies in HAU-6INTROWEB-6WEBCS. The public starter deliberately contains an unfinished page and blank identity fields. Keep student details, credentials and private course data out of this repository. Keep this guide accurate when the activity changes.

Follow [AI-DEVELOPMENT](https://tjakoen.github.io/standards/ai-development), [SESSION-LOOP](https://tjakoen.github.io/standards/session-loop), and [LOOP](https://tjakoen.github.io/standards/loop). Follow [VOICE](https://tjakoen.github.io/standards/voice) and [README-STANDARD](https://tjakoen.github.io/standards/readme-standard) for prose.

Run npm ci and npm test to verify the activity. The untouched starter must fail because its page and identity are unfinished. Verify a completed synthetic copy passes, an incorrect heading fails, and missing identity fails. Keep all completion fixtures and solutions outside this public template. Obtain an independent second pass before publication.

The page lives in src/index.html, student-facing checks in test/, and identity input in student.json. First-use instructions belong in README.md. AGENTS.md is a symlink to this file. The workflow skips only the exact public template repository; private student copies run checks. Student-owned CI is feedback, not authoritative grading evidence. Grading and Canvas setup belong in private teacher repositories. No points or deadlines are set here. Commit and push only within the task's authorization, with gitmoji subjects and no AI coauthor trailers.
